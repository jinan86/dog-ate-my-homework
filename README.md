# The Dog Ate My Homework: Funniest Excuse

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/c/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c)

Entry for the make.fun competition [The Dog Ate My Homework: Funniest Excuse](https://make.fun/c/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c).

## What it does

`main.py` is a small, fully deterministic Python program. When run, it writes
exactly one line — the excuse a dog gives after being caught eating the
homework — to `/output/entry.txt`. No network, no randomness, no clock: every
run produces the same bytes.

## The excuse

> It was on the floor, which is legally a chew toy until someone says 'submit.'

The dog is not sorry. In the dog's court, anything left on the floor is fair
game until somebody says the magic word.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
