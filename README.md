An entry for the make.fun competition [The Dog Ate My Homework: Funniest Excuse](https://make.fun/c/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c).

## What it does

`main.py` is a tiny, fully deterministic Python program. Run it and it writes
exactly one line to `/output/entry.txt`: the excuse a dog gives after being
caught red-pawed eating the homework. There is no network access, no
randomness, and no clock involved, so every run produces byte-identical
output.

## The excuse

> It was on the floor, which is legally a chew toy until someone says 'submit.'

The dog is not sorry. In the dog's court, anything left on the floor is fair
game until somebody says the magic word.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No dependencies beyond Python 3. The program creates `/output/` if needed
and always writes the same single line.
